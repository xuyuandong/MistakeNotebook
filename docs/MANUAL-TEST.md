# 端到端人工测试清单(E2E 验收)

> 配套 PRD 各节验收标准(5.1.5 / 5.2.7 / 5.3.6 / 5.4)。建议按顺序走一遍"主流程",
> 再按第 9 节过一遍边界情况。每步后的 ☐ 是验收点,不满足就记 issue。

## 0. 准备

```bash
pnpm install
cp .env.example .env      # 填入 DEEPSEEK_API_KEY(真实 AI);留空则走 mock,流程能通但结果是固定假数据
pnpm dev                  # server :8787 + web :5173
```

- ☐ 打开 http://localhost:5173 即用,无登录页(免登录)。
- ☐ 首次启动无报错;`data/app.db` 已生成。
- 两种模式建议各跑一轮:**mock(零成本走通)** → **真实 Key(验证 AI 质量)**。
- 切换密钥后需重启 `pnpm dev`。

## 1. 豆包识题(系统外)

1. 在"导入录入"页点 **复制豆包识题模板**。
   - ☐ 剪贴板内容是 `doubao-template@7` 完整模板(含 standard_solution 与可选 suggested_concepts)。
2. 打开豆包(App/网页)新建对话,粘贴模板全文,再发送 1~2 张作业/试卷照片。
   - 建议照片包含:一道有学生手写作答的题、一道空白题、一道带卷面答案的选择题。
3. 豆包返回 JSON 后整段复制。
   - ☐ 是 `[...]` 开头的数组,字段名与模板一致。

## 2. 导入与核对(PRD 5.1)

1. 回到录入页,把 JSON 粘贴到文本框,点 **导入**。
   - ☐ 显示"共导入 N 道题";重复导入同一份 JSON 时出现黄色"重复导入"提醒且不阻断。
   - ☐ 每题一张卡片:题干/标准答案/学生答案/卷面解析/错误备注已按豆包输出预填,全部可改。
2. 逐题核对,故意改错一个字段再改回;点"查看豆包原文"对照。
   - ☐ 豆包原文折叠面板能展开,与表单字段对应。
3. 点 **全部保存**。
   - ☐ 跳转错题库,题目出现在列表中。
4. 边界:把 JSON 粘贴成 `{...}` 对象或删掉某题的 `question` 再导入。
   - ☐ 报错并**定位到第几项/字段**;数据库不产生半截数据(重新导入成功即可)。

## 3. 手动录入兜底

录入页切到 **手动输入**:选学科/题型,只填题干(答案留空)保存。
- ☐ 保存成功;"学生答案留空"即空白题,不强制补答。

## 4. 更新学生分析(PRD 5.2)

到"学习分析"页点 **更新学生分析**(有真实 Key 时每题约几秒~几十秒;批量一次完成)。

- ☐ 任务进行中按钮显示 loading,重复点击不会创建第二个任务。
- ☐ 完成后:错题详情出现错误类型、证据、**三层建议**(技术性/方法性/认知性);
- ☐ "学习方法画像"卡片出现 AI 总结的习惯问题(如检查习惯/练习量),带置信度;
- ☐ 学科总结卡片更新,有生成时间;
- ☐ 待分析数量归零;Dashboard 打开本身不产生模型调用(停留页面费用不涨)。
- ☐ 英语题的“固定搭配:keep cool / hunt other animals”显示为一个“固定搭配”分类行,可展开看到两个具体概念;词性辨析优先归入已有“词汇辨析”。

## 5. 错题库与详情

- ☐ 列表顶部“全部 / 语文 / 数学 / 英语”横向按钮可切换,每个学科只显示对应错题,切回“全部”恢复完整列表;
- ☐ 列表支持学科筛选与关键词搜索(搜题干里的词);
- ☐ 详情页能看到"我的答案/正确答案/解析",复习前不剧透答案;
- ☐ 详情页“关联知识点”展示当前分类与具体概念;整理工具改名/改挂/合并后刷新详情会自动反映,不会丢关联;
- ☐ 修改"我的答案"并保存后,详情里该题回到待分析状态(下次"更新学生分析"会重算);
- ☐ 删除一道错题后,列表/搜索/复习队列中消失。

## 6. 今日复习(PRD 6.3)

新导入的错题次日到期;今天想立刻测,可临时把 data/app.db 里 review_schedules 的 due_date 改成今天,或用"智能练习"覆盖判分逻辑。走一遍:

1. **选择题/填空题(已录标准答案)**:输入错误答案提交。
   - ☐ 秒回"回答错误 · 掌握度 -x · 下次复习日期"(本地判定,无 AI 延迟)。
2. **解答题**:写一段作答提交。
   - ☐ 出现"AI 判分中… 已等待 N 秒"提示条(秒数在走),期间输入框与提交按钮禁用、不能重复提交;
   - ☐ 轮询后显示判定(正确/部分正确/错误)+ 依据 + 建议;
3. 点 **我答对了/部分对/我答错了** 改判。
   - ☐ 改判后掌握度变化显示,事件不重复(掌握度只按最终结果算一次)。
4. 点 **不知道(跳过)**。
   - ☐ 直接按放弃处理;复习排期原地不变(不倒退,下档间隔后再见)。
5. **依赖图形的错题**(题干含"如图"或【依赖图形】标记):把它的复习排期改到今天。
   - ☐ 不出现在今日复习列表;学习分析"本周复习情况"也不计它(不会永远逾期)。
6. **毕业机制**:同一道错题连续 3 次复习"正确"(间隔可把 due_date 改近加速验证)。
   - ☐ 第 3 次答对后提示"已毕业,不再安排复习",无"下次复习日期";
   - ☐ 到期列表不再出现该题;中途答错/跳过一次则连续中断,不会毕业。
7. **概念重逢复活(默认关闭)**:先在设置页 → 复习间隔卡片开启「概念重逢复活」并保存;再让一道旧题毕业(同上),导入一道同知识点的错题并点"更新学生分析"。
   - ☐ 开关关闭时:分析完成后已毕业旧题不会被复活(默认行为);
   - ☐ 开关开启时:分析完成后,已毕业旧题重新出现在复习队列,到期约在第 2 档间隔(数学约 10 天,可改 due_date 验证);
   - ☐ 复活题答对一次 → 立即再次毕业;答错 → 留在队列按常规节奏。
8. **归档退出复习**:把一道有未完成复习排期的错题归档(错题库 → 编辑/归档)。
   - ☐ 今日复习列表不再出现;恢复归档也不会自动回到队列。

## 7. 智能出题(PRD 5.3)

1. 选学科(数学)+ 来源 **出旧题**,题数 3,开始。
   - ☐ 出现"为什么出这些题"的选题理由(引用掌握情况);
   - ☐ 题目来自你的历史错题(卡片标"历史错题");
   - ☐ 题干含"如图"的错题不被选出。
2. 作答提交,观察判分(主观题等待提示同第 6 节);举报"答案错误"入口可用。
3. 再来一轮,来源切 **编新题**。
   - ☐ 生成的新题与原错题不同(改变数字/情境);数学题经过独立复核;
   - ☐ 新题题干不出现"如图"等指向插图表述,几何条件均为文字描述;
   - ☐ 主观题带评分要点,AI 判分可用。
4. 没有任何历史错题的新库直接"出旧题"。
   - ☐ 明确失败提示"改用编新题或先导入错题",不静默给空卷。
5. 历史错题全部依赖图形时"出旧题"。
   - ☐ 失败提示说明"依赖图形、无法文字作答的题目已排除",并建议改用编新题。

## 8. 学习分析与设置(PRD 5.4 / 5.5)

- ☐ 学习分析上段显示整体指标与分学科统计,下段按学科显示总结/画像/错误类型/薄弱点;Top N 可选 10/20/50/全部。
- ☐ 薄弱点一行一个分类,多成员行有展开箭头;分类错题数不会因同一道题关联多个成员而重复,分类合计样本 <3 时显示"数据不足"。
- ☐ 设置页「复习间隔」三科可改(数学默认 1, 10, 30;语文/英语 1, 3, 7, 14, 30);保存后复习推进按新间隔走(答对进档、答错不倒退);填非递增数字时保存被拒并提示。
- ☐ 设置页可改当前年级;导出 JSON / Markdown 能下载且内容完整;
- ☐ **危险区**:点「永久删除全部数据」弹出口令输入框;口令错误/留空被 403 拒绝;输入 `.env` 中 APP_AUTH_TOKEN 的值后才能清空;`.env` 未配置 APP_AUTH_TOKEN 时功能锁定(提示先配置);
- ☐ **一键清空**解锁成功后,所有数据清空,应用回到初始状态(清空前建议先导出留档)。

## 9. 边界情况抽查

| 场景 | 预期 |
|---|---|
| subject 填"物理" | 整批拒绝,错误定位到题号;不落库 |
| 超大 JSON(>512KB)/ >50 题 | 明确超限报错 |
| 豆包 JSON 手动改坏(非法 JSON) | "不是合法 JSON"报错 |
| 判分任务失败(可临时改错 models.yaml 的 key 再提交主观题) | 等待提示持续显示;约 2 分半后提示超时,可自判改判兜底;原始响应在 `data/ai-raw/judge_answer/` 可查 |
| 导入题干含"如图"的题(或 question 开头带【依赖图形】) | 详情页显示"依赖图形 · 不参与练习/复习"徽标;不出旧题、不编新题引用、不进复习队列 |
| 删除导入批次(DELETE /imports/{id},或等下一版 UI) | 未确认草稿消失,已保存错题不受影响 |
| 停掉 server 再重启 | 数据完好;正在排队的任务继续执行 |

## 10. 数据与调试

- 模型原始输入输出:`data/ai-raw/<task>/*.json`(analyze/generate/verify/judge/select);手动整理调用只记录脱敏 `model_runs`,不写概念全文日志。
- 概念整理建议:`pnpm --filter @mistake-book/server concepts:consolidate -- --subject english`;检查每条建议,只对确认项输入 `y`。
- 数据库:`data/app.db`(SQLite,可用任意 SQLite 客户端查看)。
- 重置环境:停 `pnpm dev` → 删除 `data/` → 重启(或用设置页一键清空)。
- 费用提示:分析按批(≤10 题/次)、判分与出题逐题调用 DeepSeek;单人日常用量很小,但压测时留意。

## 已知边界(不属于缺陷)

- 内网 HTTP 下 PWA"安装到桌面"不可用(浏览器要求 HTTPS),按普通网页使用即可;
- 豆包识别质量取决于照片清晰度,识别错漏靠核对页人工纠正;
- `evals/` 黄金评测集与 Playwright 自动化 E2E 尚未建立(见 README 待办)。
